# Anima Imágenes con Prompts

Página web que convierte tus fotos en un vídeo animado (zoom, desplazamiento, giro, latido, temblor) y permite descargarlo.
Incluye 70 combinaciones (40 pensadas para anuncios de TikTok Shop), selector de formato y duración, y texto de anuncio
(producto, precio, oferta y botón de compra).

Todo funciona en el navegador: las imágenes no se suben a ningún servidor.

## Cómo usarla
1. Abre la página (o `index.html` con doble clic).
2. Elige formato y duración, y una combinación del catálogo.
3. Sube tus imágenes y, si quieres, escribe el texto del anuncio.
4. Pulsa **Crear vídeo** y descárgalo.

## Publicar con GitHub Pages
Settings → Pages → *Deploy from a branch* → rama `main` y carpeta `/ (root)`.
